# Human Disease Ontology - Spanish Translation

### Description (in English)
This repository contains the code and data that was used to create and review translation of the Human Disease Ontology into Spanish.

### Descripción (en español)
Este repositorio contiene el código y los datos que se utilizaron para crear y revisar la traducción de la Human Disease Ontology (ontología de enfermedades humanas) al español.

### Ontology Files / Archivos de Ontología

- doid-international.owl (all languages / todos los idiomas): http://purl.obolibrary.org/obo/doid/translations/doid-international.owl
- Spanish only / solo español:
  - doid-es.owl: http://purl.obolibrary.org/obo/doid/translations/doid-es.owl
  - doid-es.obo: http://purl.obolibrary.org/obo/doid/translations/doid-es.obo
